# AMC Discharge Navigator

An "Apps & Agents" demo for academic medical centers. A **Copilot Studio** agent (Discharge Navigator) works a discharge plan in Teams and Microsoft 365 Copilot, hands its two writing jobs to model deployments in **Microsoft Foundry**, and shares one **Dataverse** record with a low-code canvas app and a pro-dev **Power Apps Code App**. All data is synthetic (fictional Contoso University Health).

**The docs are HTML.** Clone the repo and open `docs/index.html` in a browser. Start with `docs/status.html` for current status and next steps.
