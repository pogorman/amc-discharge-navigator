Dataverse

The three tables everything reads and writes, their choices, the synthetic seed data, the hero patient and the Command Center's KPI rules. All data is fictional (Contoso University Health), and it all lives in Dataverse (ADR-0002).

Tables

Solution AMCDischargeNavigator, publisher prefix amc. Created by scripts/create_schema.py, which is idempotent and skips tables that already exist. Display names verified on 2026-10-19: the task table is Discharge Tasks in Power Fx, with columns Discharge Barrier, Task Status and Discharge Plan.

All choices are local to their table. Values start at 417000000 and follow the label order below (first label = 417000000, then +1). The Power Fx name of the task status choice is 'Task Status (Discharge Tasks)'.

  • Barrier: a task with Discharge Barrier = Yes whose Task Status isn't Completed. In generated cases, these task types are barriers: Prior Authorization, Post-Acute Placement, Durable Medical Equipment, Home Health Referral, Transportation and Medication Reconciliation. The hero patient's tasks set the flag explicitly.
  • LACE: computed deterministically by the seed script, not by a model. L = length of stay (under 1 day: 0; 1–3: the number of days; 4–6: 4; 7–13: 5; 14+: 7). A = 3 for an emergent admission. C = Charlson index (5 if it's 4 or more). E = ED visits in the prior 6 months, capped at 4. Risk: High at 10+, Moderate at 5–9, Low below 5.

Seed data

scripts/seed_data.py writes everything relative to an anchor date (default: today). It uses a fixed random seed, so the same patients come back on every run; only the dates move with the anchor.

python scripts/seed_data.py --reset                      # replace the demo rows, anchored on today
python scripts/seed_data.py --reset --anchor 2026-10-22  # anchored on a recording date
python scripts/verify_seed.py                            # data + hero patient checks
  • Without --reset the script stops if patients already exist.
  • --reset deletes rows one at a time, so it takes about 10 minutes (KI-24). It also clears the agent's saved drafts and reopens any barrier closed in a rehearsal, because every row is recreated.
  • Re-seed right before recording so "today" in the app matches the data: Runbook.

Command Center KPIs

The rules live in code-app/src/data/metrics.ts. scripts/expected_kpis.py computes the same numbers from Dataverse, so you can check the app against the data. "Today" is the viewer's date, so the numbers drift each day until you re-seed.
