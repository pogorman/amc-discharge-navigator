The numbered flows

  1. 1Ask. A case manager chats with Discharge Navigator in Teams or Microsoft 365 Copilot. Claude Sonnet 4.6 reads the instructions and decides which skill and tools to use.
  2. 2Read and save in Dataverse. The Dataverse MCP server runs as the signed-in user, so Dataverse security still applies. It can query, search and describe, plus update_record to save a draft. It can't create, delete or change tables.
  3. 3Hand the writing to a model in Foundry. A skill calls the Foundry Deployments connector (Chat completion) with the deployment name, the system prompt and the facts. It reaches APIM with a subscription key held in your maker connection, so users never see it.
  4. 4APIM to Foundry. APIM swaps the key for its own managed identity and calls /openai/v1/chat/completions. The draft and its model field come back the same way, and the agent adds the Model: line.
  5. 5Code App. The Discharge Command Center reads plans, patients, tasks and saved drafts, and writes "Mark complete" on tasks. Reload in the drawer picks up a draft saved from Teams.
  6. 6Barrier Tracker. Built once with Apps in Copilot Studio (preview) from the nurse manager's plain-language prompt, in og-svc. It reads and edits the same tasks through a connection made as her. Beat 4 uses it live; beat 6 plays a recording of the build (ADR-0016).
  7. 7Graph recall. Microsoft 365 Copilot finds the Maple Grove and payer emails (seeded 2026-11-01 in this tenant) for beat 1. It may not find the agent chat itself.

One prompt, end to end: "Build the SNF prior-auth packet for Miguel Reyes"

  1. You type it in Microsoft 365 Copilot (flow 1).
  2. Sonnet 4.6 matches it to the prior-auth-packet skill.
  3. The skill reads DP-1001 Miguel Reyes, his patient record and every task, including the notes, through read_query as you (flow 2).
  4. The skill calls Chat completion with deployment prior-auth, the prior-auth system prompt and the labelled facts (flow 3). APIM authenticates to Foundry, and gpt-5.5 writes the packet (flow 4).
  5. The agent returns the text unchanged and adds Model: gpt-5.5-… | Draft for case manager review.
  6. You say save, and the agent writes it to amc_priorauthpacket on the plan with update_record (flow 2).
  7. In the Command Center, open Miguel's drawer and select Reload. The packet appears under Agent drafts (flow 5).
Patient instructions follow the same path with the patient-discharge-summary skill and deployment patient-summary (Mistral-Large-3, preview). The draft comes back in Spanish because that's Miguel's preferred language in the chart. When saved, it goes to amc_patientsummary with status Draft.
