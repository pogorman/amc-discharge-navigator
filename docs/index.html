AMC Discharge Navigator

A recorded "Apps & Agents" demo for academic medical centers. It mirrors the Gov "Permitting Wingman" demo beat for beat, with discharge planning as the use case. A Copilot Studio agent in Teams and Microsoft 365 Copilot reads the discharge plan in Dataverse and hands each writing job to a model deployment in Foundry. A nurse manager's app, built with Apps in Copilot Studio (preview), and a pro developer's Code App work on the same data. All data is synthetic, for the fictional Contoso University Health.

Quick start

az login --tenant <tenant-id>
python scripts/verify_seed.py          # data and hero patient
python scripts/test_foundry.py --apim  # both models through APIM

cd code-app
npm run build

App: open Discharge Command Center in Power Apps. Sign-ins and everything else: Runbook.
